# こんにちは、みすたけです

仕事では主にC/C++を使い、システムソフトウェアの開発に携わっています。
最近は、AIと一緒にコードを書く開発スタイルを日々試しながら、
趣味のプログラミングや気になった技術を、少しずつ形にしていきたいと思っています。

## いま取り組んでいること

- **AIを活用した開発**: Codex などのAIエージェントと一緒に、小さなツールやアプリを作っています
- **Rust**: Codex と一緒に、ちょっとしたアプリを Rust で作っています
- **モダンC++**: Siv3D を使って、楽しみながら学び直しています
- **ナレッジの共有**: チームの経験や知見を markdown にまとめ、属人化しにくくする工夫を試しています
- **開発環境の改善**: テストや CI など、安心して変更できる環境づくりに関心があります

## 技術

- **仕事で主に使用**: C / C++
